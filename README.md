# Dhanalakshmi Paidala Portfolio Website

## Overview

This is a personal portfolio website designed and developed for **Dhanalakshmi Paidala**, a Computer Science student specializing in the **Internet of Things (IoT)**. The website showcases academic achievements, technical skills, projects, certifications, and contact information in a modern, responsive, and interactive design.

## Features

* Responsive design for desktop, tablet, and mobile devices
* Modern user interface with smooth animations
* Light/Dark theme toggle
* Interactive navigation with smooth scrolling
* Hero section with animated background effects
* About section highlighting personal and academic information
* Technical and soft skills showcase
* Education details with academic achievements
* Featured project presentation
* Certifications and credentials section
* Contact information with quick access links
* Professional footer with social and contact links
